## 🚀 Featured Project: ProposalFlow

**AI-powered proposal generator** that transforms project requirements into winning client proposals. Saves freelancers hours of work and leverages AI to improve proposal quality and personalization.

🔗 **[View Repository →](https://github.com/Mark1q/ProposalFlow)**

**Tech Stack:** Next.js 15, Express, FastAPI, PostgreSQL, Redis, Docker, LangChain, Gemini AI

**Key Architecture & Features:**
- ⚡ **Scalable Microservices:** Separate backend (Express) and AI service (FastAPI) with BullMQ job queue for async processing.
- 🤖 **Intelligent Automation:** Dedicated AI service using LangChain and Gemini AI to generate structured, tailored proposals.
- 🔄 **Production Reliability:** Retry logic, persistent job storage with Redis, and queue monitoring via Bull Board admin dashboard.
- 💾 **Robust Data Layer:** Full CRUD operations with Prisma ORM and PostgreSQL.
- 🐳 **Containerized Deployment:** Fully defined with Docker Compose for easy development and deployment.
